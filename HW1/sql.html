History

SQL was developed by IBM in the 1974 by Donald D. Chamberlin and Raymond F. Boyce, who originally named it SEQUEL before it became SQL.

Features

SQL is a declarative language used for managing and manipulating relational databases.

Uses

SQL is popular for building applications that require data storage and retrieval from relational databases.

It is also used in business intelligence and data analysis.
